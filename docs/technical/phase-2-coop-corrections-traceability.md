## Cross-stream boundaries

Research, profession and ecology affect storage/crop production in A; position/biome/weather in B affects survival and sustainable supply. C consumes the same authorities, never independent client research or inventory. Simulation ticks, operations, checkpoint and resume identity are inseparable consistency boundaries. Frontend, server scene and aggregate projection changes share runtime paths and are integrated sequentially in this chat.

The runtime contract is [as-built gameplay](../design/phase-2-a-b-c-master-gameplay.md); authority/save/transport details are [as-built architecture](phase-2-a-b-c-architecture-contract.md). Old eight-player public rollout, anonymous-only invitation UI, missing co-op professions/machines and obsolete launcher descriptions are historical assumptions superseded by Owner requests and later releases.
