# Universal GitHub-first collaboration compatibility entrypoint

**Version:** 2.1.0. Retained for links from existing Issues.

Load `.github/PROZ0_AGENT_BOOTSTRAP.md` and the current adopted role pack. “Producer” in legacy Issues means their Coordinating PM. PM retains lifecycle accountability; direct specialist communication and a recorded preauthorized review/activation route may proceed without a redundant PM courier step.

Existing tasks, criteria, scope and owners remain valid. New policies apply to live tasks only after required reconciliation; no automatic ownership transfer or dropped acceptance criterion. Specialists do not take unclaimed work without an explicit or conditional PM authorization. Skill guidance does not replace domain authority. Use ROLE_RUNTIME_PROTOCOL for reload and COMMUNICATION_PROTOCOL/DEFINITION_OF_DONE for replies and evidence.

For deterministic work selection, dependency checks, downstream activation and correction recovery, follow [COMMON_EXECUTION_CONTRACT](COMMON_EXECUTION_CONTRACT.md). Historical Role → PM → Next Role wording preserves PM accountability; it does not require a PM message relay for a preauthorized specialist review or correction.
