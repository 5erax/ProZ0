## Evidence ladder

**TRACE:** a visible local remnant may invite attention. Its direction is an observed arrangement, not a guaranteed route, quest instruction or location reveal.

**SITE:** record deliberate construction, material/condition and absence at this encounter. A single site must stand alone; inspecting it cannot solve a civilization.

**RUIN COMPLEX — PROPOSED:** a larger arrangement supports comparison between subspaces. Repeated interfaces, incomplete alignment or different construction layers are candidate observations only if actually authored and visible. Size does not authorize a new historical event.

**LATER RECONTEXTUALIZATION — PROPOSED:** a later observed comparison can challenge an interpretation while leaving the original material fact true. If a new clue is absent, earlier evidence still makes sense. Discovery order and missing-clue tests are required.

The documentation IDs below use taxonomy conventions with a `P2` suffix namespace to avoid overwriting existing examples. They are authoring references, not runtime IDs or new schema.

## Spatial versus journal communication

Spatial consumers may show visible alignment, interruption, weathering, covered edges and absence at the encountered site. They cannot paint translated symbols, human/nonhuman anatomy, a catastrophic event or a functional blueprint without a source. Journal records what was inspected, names what remains unresolved, and may explicitly label hypotheses after enough actual comparisons.

Current `GameUiMessages.networkHint` says similar conduits/repair interfaces suggest a supply network after two inspected templates. This is an existing interpretation, not proof. Proposed correction: require the compared feature to exist on both observed sites; otherwise use neutral comparison copy. Current relay coordinate disclosure is a knowledge-boundary issue recorded in the companion spatial brief; narrative documentation does not disable the relay or change its rewards.

## Redundancy, revisit and blocked requests

Each implemented clue needs one local observation readable without prior clues; comparisons add context, not eligibility. Use independent channels only when both report the same supported fact (shape plus inspected wording), never a second compulsory item. A missed optional clue cannot break comprehension. Revisit must distinguish **new comparison** from **changed physical condition**, recording the latter only if authority actually changed the site. Do not retcon construction or alter old save evidence to fit a hypothesis.

`NARRATIVE_BLOCKED`: a named builder species, humanity ancestry, a definitive temple/weapon/network function, dated civilization collapse, a decoded Shard capability, or final Layer-3 answer. None is needed for the present support package. Such rows require separate Owner canon decisions before authoring, while unaffected route/readability work continues.
