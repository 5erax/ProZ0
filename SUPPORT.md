# ProZ0 Support

Use the channel that matches the request.

## Bug / reproducible defect

Open a **Bug Report** Issue and include the exact commit/build, reproduction steps, expected result, actual result and evidence.

## Product/design idea

Open a **Proposal / Discovery** Issue. A proposal is not automatically an approved requirement or activated implementation task.

## Core-team project work

Use the ProZ0 Task template and follow the task-lock / Coordinating-PM workflow.

## Development setup

Start with:

- `README.md`
- `docs/development/phase-0-runtime.md`
- `docs/technical/phase-1-build-ci-reproducibility-audit.md`

## Security issue

Follow `SECURITY.md`; do not post sensitive exploit details publicly.

## General questions

GitHub Discussions is the intended home for Q&A and non-task conversation once repository-level Discussions is enabled. Until then, keep Issues limited to actionable bugs, proposals and project work.
